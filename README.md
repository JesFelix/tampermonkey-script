## 功能概览

| 脚本 | 功能 | 适用网站 |
| --- | --- | --- |
| [黄果小窗视频播放](script/huangguo/picture-in-picture.js) | 在视频播放操作区域增加“小窗播放”按钮，使用浏览器原生画中画功能播放视频。 | 黄果视频相关播放页 |
| [黄果去广告](script/huangguo/ad-removal.js) | 移除播放页面中的指定广告区域，并监听页面动态变化。 | 黄果视频相关播放页 |
| [抖音当前视频下载辅助](script/douyin/download.js) | 捕获当前播放视频的地址，在播放器操作区域增加下载按钮。 | 抖音网页版 |

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开本项目中对应的 `.js` 文件。
3. 点击 GitHub 页面右上角的 **Raw**。
4. Tampermonkey 会打开安装页面，确认脚本信息后点击安装。
5. 访问对应网站并刷新页面。

也可以在 Tampermonkey 控制面板中新建脚本，将对应文件的完整内容复制进去并保存。
