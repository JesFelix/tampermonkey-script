## 功能概览

| 脚本 | 功能 | 适用网站 |
| --- | --- | --- |
| [黄果短剧](script/huangguo/huangguo-short-drama.js) | 去除播放页面广告，并在播放器控件中添加画中画（小窗播放）按钮。 | 黄果视频相关播放页 |
| [抖音当前视频下载辅助](script/douyin/download.js) | 捕获当前正在播放的视频地址，并在播放器操作区域添加下载按钮。 | 抖音网页版 |

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开本项目中对应的 `.js` 文件。
3. 点击 GitHub 页面右上角的 **Raw**。
4. 在 Tampermonkey 安装页面确认脚本信息并点击安装。
5. 访问对应网站并刷新页面。

也可以在 Tampermonkey 控制面板中新建脚本，将对应文件的完整内容复制进去并保存。

## 使用说明

### 黄果短剧

进入匹配的黄果视频播放页面后，脚本会自动移除指定广告区域，并等待播放器控件加载。

点击播放器中的小窗播放图标即可进入浏览器画中画模式，再次点击或关闭画中画窗口即可退出。脚本使用浏览器原生 Picture-in-Picture API，浏览器需要支持该功能。

### 抖音当前视频下载辅助

1. 打开抖音网页版并播放目标视频几秒钟。
2. 在播放器操作区域找到下载图标并点击。
3. 脚本会尝试将当前播放视频下载为 MP4 文件。

如果提示尚未捕获到播放地址，请先继续播放几秒钟后重试。部分视频、浏览器策略或网络环境可能导致无法直接下载，此时脚本会尝试在新标签页打开视频地址。
