# Tampermonkey 用户脚本

本项目收录用于黄果视频、抖音和 X（原 Twitter）网页版的 Tampermonkey 用户脚本，提供播放页面增强及视频下载辅助功能。

## 功能概览

| 脚本 | 功能 | 适用网站 |
| --- | --- | --- |
| [黄果短剧](script/huangguo/huangguo-short-drama.js) | 移除播放页指定广告区域，并在播放器控件中添加画中画按钮。 | 黄果视频播放页（匹配 `/video/` 路径） |
| [抖音当前视频下载辅助](script/douyin/dy-video-download.js) | 识别当前播放视频，在播放器操作区域添加下载按钮，并尝试下载为 MP4；下载失败时在新标签页打开视频地址。 | 抖音网页版 |
| [X 视频下载](script/x/x-video-download.js) | 在含视频的推文操作区添加下载入口；显示推文中的视频及封面，支持选择 MP4 分辨率，或下载并合并支持的 HLS（m3u8）视频流。 | X / Twitter 网页版 |

## 安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 在本项目中打开对应的 `.js` 脚本文件，并在 GitHub 文件页面点击 **Raw**。
3. 在 Tampermonkey 安装页面确认脚本信息并安装。
4. 打开对应网站并刷新页面。

也可以在 Tampermonkey 控制面板中新建脚本，将对应 `.js` 文件的完整内容复制进去并保存。

X 脚本需要 Tampermonkey 提供跨域请求和下载权限；请按安装时显示的权限提示授权。部分功能依赖已登录的 X 页面会话。

## 使用说明

### 黄果短剧

进入匹配的黄果视频播放页后，脚本会移除指定广告区域，并等待播放器控件加载。点击播放器中的小窗图标即可进入浏览器原生画中画模式，再次点击图标或关闭画中画窗口可退出。此功能要求浏览器支持 Picture-in-Picture API。

### 抖音当前视频下载辅助

播放目标视频几秒钟，让脚本捕获当前播放流，然后点击播放器操作区中的下载图标。若提示尚未捕获到地址，请继续播放片刻后重试。网站页面结构、视频资源或浏览器策略可能影响下载；直接下载失败时脚本会尝试在新标签页打开资源地址。

### X 视频下载

在 X 或 Twitter 网页版打开含视频的推文，点击推文操作区新增的 **下载** 按钮。弹窗会列出该推文检测到的视频及可用格式或分辨率；选择所需项目后点击 **下载**。MP4 会按所选分辨率保存；m3u8 流会尝试下载并合并分片，处理过程中弹窗按钮会显示进度。

X 会话失效、接口变化或视频流采用不支持的加密方式时，脚本可能无法获取或下载视频。m3u8 下载支持未加密及 AES-128 流；其他加密方式暂不支持。

## 注意事项

- 脚本依赖目标网站当前的页面结构和接口行为，网站更新后可能需要调整。
- 建议使用最新版 Chrome、Edge 或其他兼容 Tampermonkey 及相关 Web API 的浏览器。
- 视频下载功能仅供个人学习和研究使用。请遵守目标网站服务条款及所在地法律法规，并尊重视频作者著作权，不要下载、传播或使用未经授权的内容。
